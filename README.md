# Lumen Sports AI Auto

Esta versión busca partidos automáticamente en ESPN para un rango de fechas.

## Deploy
- Sube `app.py` y `requirements.txt` a GitHub.
- En Streamlit Community Cloud selecciona `app.py`.

## Limitación importante
Los porcentajes actuales son una línea base experimental. Para predicciones útiles se requiere conectar estadísticas históricas, lesiones, alineaciones, cuotas opcionales y modelos específicos por deporte, además de validación fuera de muestra.
